
# 👁️ Visão Acessível

Site de acessibilidade desenvolvido para auxiliar pessoas com
baixa visão durante a navegação na internet.

## ♿ Recursos

O projeto possui diversas ferramentas de acessibilidade:

- 🔠 Aumentar o tamanho das letras
- 🔡 Diminuir o tamanho das letras
- 🔍 Lupa para ampliar o conteúdo
- 🔊 Leitor de texto
- ⏹️ Parar a leitura
- 🌓 Modo de alto contraste
- 📱 Layout responsivo para celulares
- ⌨️ Suporte básico à navegação por teclado
